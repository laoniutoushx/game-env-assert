# V9：叶影抗闪烁与叶片高光、暗面

基于 V8 提交 `36bba45`，候选入口 `res://render_v9.tscn`。`launch.ps1` 打开实机；F9 在完整 V8 基线与 V9 间切换，F8 切换景深，F5 切换风动，右键旋转、WASD 平移、滚轮缩放。锁定 V4 仍为项目默认入口。

## 经实机隔离确认的范围

- 在本轮选定路面影区，关闭植物投影显著降低时间变化；关闭叶片高光、法线或 SSAO/SSIL 基本不改变该影区指标。相机平移期间没有可见模型 LOD 切换。因此，所测地面黑影主要指向密集叶片投影的采样，而不是把叶片材质提亮就能解决。这个结论不覆盖全场景所有类型的闪烁。
- 几何蕨类/花簇的叶脉和法线纹理确实未生成 mipmap。V9 以共享运行时缓存补齐两张纹理的 mip 链，并重新归一化法线 mip；V8 原纹理、导入配置和绑定均保留，可完整还原。
- 树叶粗糙度采用法线变化率限制和 0.60 下限，保留正常高光；叶片背光贡献只增加 15%，不改树干/花瓣，不用自发光或整体曝光提亮暗面。材质 AO 保持原值。

## 最终选择与否决记录

保留原生 2K、MSAA4、TAA 关闭、Medium 阴影滤波、单张 4096/32 位阴影贴图、60m 覆盖，以及安全偏移 0.7 / 0.025。最终太阳角直径为 0.3°：0.9°/1.2° 在本测试中更不稳定；High 滤波有抗闪烁收益，但两轮 P95 34.106 / 33.480ms、GPU 增量约 2–3ms，超预算；8K 贴图也未改善所测指标。没有为了跑分而关闭阴影。

0.45° 在短测试中改善约 32%，但严格的 600 帧慢平移只有约 20.5%，未采用。首次滞回实现错误保留了构建器 LOD0，使候选与基线阴影面积不同，也已否决并保留原始记录。修复后第一次按当前相机选择与 V8 一致的级别，再在 13、28 两个阈值外使用 ±8% 滞回；父级硬阈值管理器在候选模式下不再反复换回网格。没有锁定全场高模或提高投影代理级别。

太阳方向、颜色、能量、曝光、布局、真实连续体积空气和景深均保持不变；复用 V4 静态间接光缓存并校验其源指纹。本轮不处理水渍，不使用付费生成。

## 验收与复现

连续记录包含 V8、V9 各 300 帧静止、300 帧风动，以及各 600 帧慢平移、LOD 阈值往返和完整环绕，共 4800 帧。记录使用真实 Godot Forward+ 输出、固定模拟步进 30Hz，每个引擎渲染帧均保存；这不是稀疏机位截图拼接，也不把离线视频播放帧率当成游戏性能。实际性能另测，无截图读回和视频编码负载。

数值指标使用无损原生 PNG 路面样本，按相机与固定石板平面重投影到 256×96，计算 8 位亮度的时间二阶差分 P95。固定植物影区遮罩由“关闭植物投影”与 V8 基线时间均值之差大于 5/255 得到，共 1555 像素；不会针对候选重新挑选遮罩。门槛为同轨迹、关闭风动时此影区指标下降至少 30%，阴影覆盖相对变化不超过 10%，平均明度变化不超过 5%。同时报告完整路面 ROI 的结果。它不是全场景感知质量或概念图相似度评分。

连续视频、同步播放、同机位及粗糙度对照见 `review.html`；数据见 `temporal_analysis.json`、`validation.json`。逐帧样本与视频位于本地忽略的 `captures/`，可由脚本重新生成。失败样例保留在 `bad_lod_combined_*`、`rejected045_combined_*`，不用于达标判断。

Python 依赖为 numpy、Pillow。先运行 `python render_v9/prepare_tools.py` 获取本地 FFmpeg（工具包不提交 Git）。`run_reviews.ps1` 提供 `Diagnose`、`Tune`、`Tune2`、`Temporal`、`Cases`、`Perf`、`Final`、`Smoke`；`finish.ps1` 用于已完成基线和最终慢平移录制后的验收收尾。本轮基线录制通过 `Temporal`，最终慢平移来自显式 0.3° 的 `PanTrial`，其余候选片段通过 `TemporalRest`。

仍需注意：风动造成的真实叶片/影子移动不是应当删除的现象；细叶亚像素边缘也可能有残余闪烁。本轮不宣称完全消除闪烁或达到概念图 90%。

本轮结果：600 帧同轨迹慢平移的受测植物影区指标下降 30.17%，阴影覆盖相对变化 3.97%，平均明度变化 0.12%；完整路面 ROI 指标下降 4.58%。阈值往返测试的植物 LOD 切换从 10 次降为 0 次。原生 2K 两轮各 600 帧 P95 为 29.883 / 29.898ms，同期 V8 基线为 31.875ms，绘制提交均为 986 次。F9 还原平均像素误差约 0.039/255。

10 段 MP4 已完整解码核验，共 4800 帧，无解码错误。读回/保存原生帧的工具采集速度约 8fps，不代表游戏速度；固定模拟步进和视频回放为 30Hz。旧录制元数据中误命名的 `fixed_fps` 字段表示观测采集速度，分析器兼容读取；新录制改用 `capture_observed_fps`，原始记录不改写。
