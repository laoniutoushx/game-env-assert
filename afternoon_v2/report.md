# AFTERNOON v2 实机迭代

本轮聚焦环境渲染，不增加溪流、桥、炮塔、敌人或 UI。旧版 `afternoon.tscn` 保留。

## 已实施

- 午后光束：三个世界空间 FogVolume 密度通道，接受 DirectionalLight 和树影。不是镜头平面、粒子条或自发光假光束。属于美术塑形的三维散射介质，不宣称均匀空气自然产生了同样的光路。
- 体积范围 60m，128×64 体积采样；关闭景深的多视角检查也保留光束。两个主树冠采用更细的阴影代理，叶片与阴影使用相同的世界空间透光开口。
- 水面停用后关闭收益有限的 SSR，保留材质天空反射；此版本不宣称具备水面屏幕空间倒影。
- 叶片在 22–30m 之间连续渐退微观法线、AO 和 ORM 采样，近景保留完整细节；颜色纹理、透明遮罩和空间轮廓不降低分辨率。
- 恢复阴影专用网格的导入 LOD（原先偏置 100 几乎禁用），可见模型的三级 LOD 与材质轮廓保持独立。
- 扫描蕨类/灌木恢复导入器正常的屏幕尺寸 LOD 偏置 1，近距离仍选择完整资源，避免远处一直强制高细节。
- 浅景深采用低采样、关闭抖动的滤波；清晰检查模式关闭景深。该调整只减少虚化采样成本，没有降低主渲染分辨率。
- 表面太阳颜色、能量与曝光保持 v1，石板材质去黄，环境填光转天空蓝，地面降低饱和与大色斑对比。
- 28 组前景植物物理外移，植物数量未增加；叶色分深绿、青绿、新叶三组，降低塑料高光。
- 增加 48 个真实小碎石，四块符文石板使用放大的程序化刻纹，重新生成凹刻几何。
- 两个独立水面候选均未通过视觉评估：第一个过暗，第二个仍像贴片。因此默认关闭额外水面，仅保留湿石与浅凹槽，避免白圆盘/黑补丁。
- 215 个静态网格采用独立 v2 间接光烘焙。几何一致的非路面资源复用核对过顶点位置的 UV2；改变的路面使用新 UV2。运行时校验材质与配置指纹，防止读取过期缓存。

## 验收入口

RTX 3060，原生 2560×1440、4×MSAA、内部分辨率比例 1.0，电影模式两轮各 600 帧：P95 31.743 / 32.012 ms，GPU P95 31.020 / 31.059 ms，两轮均无最小化重启。仍仅接近 30fps 预算，没有充裕的性能余量。

保持叶片透明遮罩与世界空间树冠开口的 ID 测量：主视角植被覆盖路径 0.28%，左侧 1.70%，右侧 2.06%，32°低角度 4.80%。低角度仍有少量叶缘遮挡，不宣称所有角度完全零遮挡。

打开 [review.html](review.html) 查看实机多视角、旧版对照和移动相机序列；[validation.json](validation.json) 记录最终测试结果与源文件指纹。

相机：右键旋转，WASD 平移，滚轮缩放，R 重置；F8 在浅景深展示和关闭景深的清晰检查之间切换。树木与灌木是具有空间体积和分枝的模型，叶片仍使用常见的 alpha-tested 叶面纹理；不是整棵树朝向镜头的 billboard，也不宣称每片叶子都做了实体厚度。

## 尚存差距

光束已经可辨，但局部光路仍较规则。泥土与路面仍有材质重复，蕨类叶形和门体轮廓细节仍偏简单；色彩与构图还没有达到概念图。水面未完成，缺失的桥溪与玩法元素也不在本轮范围。没有认定达到 90% 还原度，本轮未消耗 Meshy 积分。

移动序列故意包含低至 10° 的压力视角：该角度可见场景外空地、灰色地平线，反向低角度也有树冠遮挡。正常右键相机限制为 40°–70°，F4 才开放 10°–80° 检查模式；不能把极低角度序列说成已完成的可玩镜头。常规四机位的遮挡限值通过，不等于整个 360° 调试范围均无遮挡。

本轮验收对象是 Godot 工程运行，不包含发行包导出。程序化符文读取源 PNG 的警告尚在，单独导出发行包前须改为正常导入资源加载并重新验收。

烘焙编辑器退出时的原生节点访问诊断单独记录在 `editor_teardown.json`；运行时脚本、着色器和资源错误仍按失败处理。
