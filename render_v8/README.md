# V8：细化太阳半影，保留安全阴影偏移

基于已提交的 V7（`7e55067`）。候选入口 `res://render_v8.tscn`，运行 `launch.ps1`；F9 对照 V7，F8 切换景深，右键旋转、WASD 平移、滚轮缩放、R 重置。项目默认仍为锁定 V4。

## 实机对照后的选择

1. 否决小偏移方案：`shadow_normal_bias=0.35`、`shadow_bias=0.015` 在当前石板、石块上产生明显斜向自阴影条纹。失败截图保留，不能把更多暗纹当成细节提升。
2. 保留 V7 的安全值：法线偏移 0.7、深度偏移 0.025。
3. 仅将太阳角直径从 1.2° 收到 0.6°，减少过宽半影对树叶投影细节的模糊。主视角的路面叶影和柱体阴影轮廓变化比上一轮树冠法线更容易辨认。

太阳方向、颜色、能量、曝光、SSAO/SSIL、真实连续空气介质、景深、模型、材质与布局保持 V7 配置。阴影贴图仍为单张 4096 / 32 位、Medium 滤波、60m 覆盖；没有人为光束或树冠开口，也没有处理水渍。静态间接光缓存继续复用，运行时校验源指纹。

## 验收与限制

`run_reviews.ps1 -Round Cases` 生成三种方案的全景、近景、左上切片。最终 `fine` 已撤回小偏移，只改变太阳角直径；旧组合失败样例以 `rejected_` 保存。`-Round Verify` 运行同期 V7 性能基线、两轮各 600 帧 V8、14 张固定视角、96 帧环绕及交互检查。`finalize.py` 校验结果并生成 `validation.json`、`review.html`。

原生 2560×1440、MSAA4、内部缩放 1；性能要求为 P95 ≤33.3ms、GPU P95 相比同期基线增量 ≤1ms。移动检查重点为阴影覆盖、条纹、叶影闪烁及路径可读性。F9 验证三项太阳参数还原、材质状态和相机不变，F5 验证风动及碎石状态。

该改动提高实时阴影辨识度，不等于增加模型细节。植被形态、地面层次和整体场景内容与概念图仍有差距，不能据此宣称达到 90%。默认版本不自动晋升。

## 本次结果

RTX 3060 / Vulkan Forward+：同期 V7 P95 32.469ms；V8 两轮各 600 帧 P95 31.006 / 31.454ms，GPU P95 30.446 / 30.894ms，绘制提交均为 986 次。满足本轮预算，不将一次同期基线差值直接宣称为稳定加速。

14 张固定视角、96 帧环绕记录、相机/景深/风动/分辨率切换检查通过，F9 还原平均误差 0.056/255。环绕及低角度检查未发现此次引入的明显条纹或阴影覆盖断层；亚像素叶影仍受实时阴影贴图采样限制。对照和失败样例见 `review.html`，完整数据见 `validation.json`。
