# V5：基于锁定 V4 的低成本光影细化

V4 已由用户认可并锁定，默认入口仍为 `res://render_v4_live.tscn`。完整快照位于 `work/environment_releases/render_v4_accepted_20261103`，包含源码、资产、烘焙结果和验收图。候选入口为 `res://render_v5.tscn`，运行本目录 `launch.ps1` 可打开。

本轮不增加模型、贴图、光源，不处理水渍，也不改变太阳方向、曝光、色调映射及景深构图。

## 保留的细化

1. 叶片：小幅增加背光透射近似，并减轻部分贴图 AO 的过重暗部。保持真实几何轮廓与原有阴影。
2. 接触阴影：SSAO 半径从 0.32m 收到 0.23m，SSIL 半径从 2.5m 收到 1.6m，使暗部更集中在接触位置，避免宽泛暗圈。这是细节调整，主视角变化较小。
3. 体积光：保留连续空气介质和真实遮挡。减弱贴近地面的雾密度，并把深度分配从近相机优先的 2.0 调至 0.7，给较远树林更多采样。保持 160×80 采样设置。

这些是渐进改善，远景差异不大；上左弯道近景中，低处雾幕与接触暗部变化更容易判断。没有新增固定光束或人为树冠开口。

## 性能和交互

初版为每个实例复制材质，造成绘制提交增加；最终按原共享材质复用，提交恢复至同期基线的 986 次。原生 2560×1440、MSAA4、RTX 3060、Vulkan Forward+：同期 V4 基线 P95 30.297ms；V5 两轮 600 帧 P95 30.111 / 30.328ms。差异接近运行波动，不声称显著加速。

F9 在当前候选和 V4 基线之间切换；相机、曝光和构图保持一致。F8 切换景深展示/清晰检查，右键旋转，WASD 平移，滚轮缩放，R 重置。

修复了候选中 F5 风动会把路边碎石转换成草材质的问题：保留碎石材质和投影设置。此修复不改写锁定 V4。

已检查 14 张固定视角和 96 帧移动记录；F9 还原平均像素误差约 0.088/255，相机变换保持一致；F5、相机、投影及分辨率切换检查通过。最终结果及源码摘要见 `validation.json`。

本轮只改变动态植被的背光响应和实时屏幕/雾效果，复用 V4 静态光照缓存；太阳、静态材质和几何没有改变。完整锁定文件校验由 `finalize.py` 执行。

V5 保留为独立候选，不覆盖已认可的 V4 默认版本。
