# RENDER V4：光影迭代

范围：日光/天空补光、树冠和接触阴影、景深、连续空气体积散射。水渍暂停，本轮不修改模型。

默认入口 `res://render_v4_live.tscn`；自动验收入口 `res://render_v4.tscn`。窗口标题含 RENDER V4。

右键旋转，WASD 平移，滚轮缩放，R 重置；F8 切换景深展示/清晰验收，F3 切换投影，F2 原生 2K。运行 launch.ps1 可打开交互验收窗口。

关键修正：旧阴影距离 42–45m 且远处淡出，使远处树冠及雾中的遮挡变弱；改为覆盖场景的 60m 并在范围内保持阴影。比较分区及偏移后，采用 4096 单张 32 位方向光阴影图，降低条纹并保留树冠光斑。此选择针对本场景相机，不能直接泛化到大型开放世界。

取消预塑光柱和人为树冠开口。连续空气介质只定义树林内的空气分布，明暗由方向光和几何阴影计算；采用 Godot 实时体积散射近似，不是离线路径追踪。左侧仍有局部雾感，尚未达到参考图的丰富光束层次。

日光暖色、环境补光冷色；保留 ACES，未采用对照中使画面变平的整套 AgX/天空补光组合。改善地表材质过渡及部分树冠法线。接触暗部使用 SSAO 和适量 SSIL。景深随相机更新，将完整路径深度区间留在焦内；清晰验收关闭景深。

220 个静态网格重新烘焙。先前高采样版本 P95 38.901ms 未通过；最终采用 160×80 雾采样设置、半分辨率 SSIL 和中等阴影过滤。最终测试及指标见 validation.json：14 张固定视角、96 帧移动记录、两轮 600 帧、相机功能检查。

测试环境为 RTX 3060 / Vulkan Forward+ / 2560×1440 / MSAA4 / 内部分辨率 1.0。性能并不代表其他显卡或导出平台。烘焙编辑器退出有独立记录的 get_node teardown 诊断，运行时检查通过。

本轮已形成可用的光影改进版本；尚未通过最终概念图一致性验收，不宣称达到 90%。剩余光影差距包括：部分植物暗部仍偏黑、逆光叶片层次不够细腻、空气光束仍有雾团感。继续迭代应以这些具体差距为准。
