# V7：树冠受光连续性

基于已提交的 V6（`ba38227`），候选入口为 `res://render_v7.tscn`，运行 `launch.ps1`。F9 在 V7 与 V6 之间切换；F8 切换景深，右键旋转、WASD 平移、滚轮缩放。项目默认入口仍为锁定 V4。

## 本轮修改

原树冠着色器已有向树冠外侧平滑法线的能力，但树木实例的混合权重为零。叶片按各自平面法线受光，形成细碎、不连续的亮暗块。本轮只针对 15 组树木的高、中、低三级叶片网格（共 45 个）启用轻量平滑；茎干和其他植物不改变。

对比 0、0.25、0.45 三档，采用 0.25，以保留叶片方向差异。同步正交化切线/副切线，保持法线贴图的坐标基底一致。新材质按来源共享，保留实例调色和风动。

这是一项局部受光改善。树冠的实际轮廓、alpha 遮罩、投影几何、太阳、曝光、连续空气介质与景深均保持 V6 配置，没有通过削弱真实阴影来抹平树冠，也没有新增模型或贴图。

性能复核时移除了新树冠着色器内已禁用的人为开口逻辑及世界坐标插值。当前版本本来就没有启用这些开口，因此此项只清理残留计算，不改变真实树冠遮挡。

## 复核

`run_reviews.ps1 -Round Cases` 生成三档同机位及近景对比；`-Round Verify` 生成同期 V6 性能基线、两轮各 600 帧的 V7 性能、14 张固定机位、96 帧环绕和交互检查。`finalize.py` 检查结果与已有跟踪文件，生成 `validation.json` 和 `review.html`。

性能要求为原生 2560×1440 / MSAA4，P95 ≤33.3ms，GPU P95 相对同期基线增量 ≤1ms。F9 必须还原 V6 材质与相机，F5 不得改变碎石材质。

每轮验收后提交 Git，再进入下一轮，约定已写入项目 `AGENTS.md`。

最终检查通过：14 张固定视角、96 帧环绕，F9 基线还原误差 0.038/255，相机、风动和碎石状态保持正确。原生 2K 两轮各 600 帧 P95 为 33.194 / 33.175ms，绘制提交均为 986 次；仅余约 0.11ms 的预算空间。同期 V6 基线也存在波动，因此不将本次耗时差值宣称为稳定加速。清理前两次超预算数据保留在 `validation.json`。

改善主要体现在靠近树冠的局部受光，游戏主视角差异很小；没有达到整体画质跃升。V7 保持独立候选，默认 V4 及 V6 来源文件均不改变。
