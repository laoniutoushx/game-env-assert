# 资产规范 v2：以可编辑几何、真实受光和实机验收为准

## 入库原则
core：必须通过结构、材质、移动与艺术评审。wip：技术可加载或预算通过，但造型/材质仍有差距。reference：外部源与旧版本。当前新标杆仍为wip，五棵原树为reference。目录位置不等于认证结果。

## 几何与空间
1单位=1米，根部落地，整体变换明确，导出处理Z-up/Y-up。LOD0目标≤8000三角面，LOD1≤4000，LOD2≤1500。优先剪影、分叉、空间叶团，不能把叶片全部压成三角形来过预算。新标杆使用16三角面/叶以改善曲线，总量7144。

叶团有明确空间位置。近景叶轮廓由几何构成；薄叶允许双面受光，不等于整树billboard。LOD2可以使用真实三维叶团体积，但应按实际游戏投影尺寸检验切换差异。不得将主冠参考球直接作为全场实心投影代理。

## UV与贴图
Base Color为固有色，sRGB；Normal为OpenGL，非颜色；ORM为R=AO、G=Roughness、B=Metallic，非颜色。树木非金属。颜色不烘焙固定方向强光。植物AO与固有色分开，不重复压黑。叶片1024、树皮2048为本资产实测起点，保留可重烘焙源；不要求所有资产一律4K。mipmap与各向异性过滤必检。

叶图集允许有意复用UV；树皮密度和接缝以镜头检查为准。顶点色R=遮蔽权重（1无遮挡），G=组间变化（0.5中性），B=风动权重。顶点色是数据，不直接当最终颜色。

## 统一材质体系
树皮：ORMMaterial3D。叶片①②：leaf_pbr.gdshader；③：leaf_toon.gdshader。两类叶片受光共享leaf_common.gdshaderinc的纹理、AO、颜色变化与风动输入。统一的是接口与规则，不强求不同表面同一Shader。外部tres必须绑定到真实MeshInstance表面，而非父Node3D。

保持天空/颜色环境补光；太阳能量必须影响画面，不归一化抹掉强度。卡通色阶仍接收真实阴影与灯光色，不用自发光抬亮暗面。叶团法线在源资产局部编辑/烘焙，不按世界坐标格子虚构团块。

色板是方向参考，不对所有材质/受光像素强制≤65%饱和度。路径可读性是整体构图要求，不等同于植物任何像素都必须比路径暗。应在色调映射后检查实际明度层次。

## 可编辑资源与验收
保存blend、纹理源节点、GLB、外部tres、灯光preset资源。场景引用源模型，避免把同一网格写进三份巨大的tscn。参考辅助体、烘焙画布不得进入导出。对象名、UV、颜色属性保持稳定。

固定中性/午后/阴天三套光、整体/俯视/近景三机位；三风格共27组。连续环绕、关灯、反向灯、1/4宽高与LOD往返必须检查。技术检查通过不自动判为概念图90%或商业成品。

本轮检查与证据在benchmark/reports和benchmark/review.html；人工跟做方法见benchmark/制作与跟做.md。
