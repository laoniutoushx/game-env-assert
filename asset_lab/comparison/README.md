# 树模型对比
打开 `res://asset_lab/tree_comparison.tscn`，按F6。

数字键1：原V9 Poly Haven树。
数字键2：Meshy阔叶树。
数字键3：Meshy常绿树。
数字键4：Fab tree_1。
数字键5：Fab tree_2。

一次只显示一棵，切换时保留相机位置，Home复位。右键+WASD移动，Q/E升降，Shift加速，Ctrl慢移，滚轮调速。当前选择显示在窗口标题及Output中。

新增候选按几何包围盒统一到4.5米高、树根落地，保留原材质，采用相同中性灯光。Fab两棵模型可能来自同一套件，应比较实际外形差异。每个inspect_开头的场景可单独打开，模型场景不挂运行时构建脚本；切换脚本仅用于显示选择。prepare_comparison.gd是一次性准备工具，运行场景不调用它。

已通过Godot实例化检查：Meshy各1个表面，Fab分别14和9个表面，每个表面均绑定颜色贴图。此检查不代表视觉质量或完整PBR质量通过，也不代表Fab资产许可审计完成。请比较叶片剪影、侧面厚度、枝叶连接、纹理清晰度及逆光暗面；近看成团的生成模型叶片不一定优于薄叶片模型。
