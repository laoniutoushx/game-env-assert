# V6：叶片受光和关键树影修复

独立候选入口 `res://render_v6.tscn`，运行 `launch.ps1`。默认项目仍打开已锁定的 V4。F9 在 V6 与 V5 全效果基线之间切换，F8 切换清晰/景深；右键旋转、WASD 平移、滚轮缩放、R 重置。

本轮保持太阳方向、曝光、场景布局、连续体积雾、景深与原生 2K/MSAA4 配置，暂不处理水渍。

## 已确认的原因与修复

- 蕨类/花簇几何模型的各级 LOD 均有完整切线，无需重建模型。旧材质声明了叶片法线纹理但未使用；V6 接入纹理，只作用于绿色叶片，强度采用 0.20，粗糙度在 0.68–0.82 之间变化，保留茎和花瓣的独立响应。
- 使用当前 Godot 4.7.2 的标准双面材质与法线缓冲逐点对照：引擎已经处理背面方向，旧着色器再翻转 NORMAL 会反转受光。V6 的几何和贴图叶片均去除这次多余翻转。对照装置和数值保存在 `normal_fixture.gd` 与 `captures/normal_fixture.json`。
- 仅将最接近左上树冠区域的两棵树的投影代理由低模升级为中模，LOD bias 改为 4。可见模型、位置、alpha 遮罩不变；仍由真实树冠遮挡太阳与连续空气介质形成体积光，没有新增光柱或遮挡片。
- 材质 AO、SSAO、SSIL、太阳阴影通过单独关闭进行诊断。保留材质 AO 系数 0.50，避免在没有证据时抹平根部接触层次。

## 验收

`run_reviews.ps1` 提供 Probe / Fixture / Cases / AO / Final / Motion / PerfBaseline / Perf / Smoke。`finish.ps1` 运行组合验收并生成 `validation.json` 和 `review.html`。性能门槛为同期 V5 对比下 GPU P95 增量不超过 1ms、帧耗时 P95 不超过 33.3ms，两轮各 600 帧。

14 张固定机位、96 帧移动记录覆盖清晰和景深模式；F9 检查相机不变、基线材质和投影代理还原，F5 检查所有候选材质与碎石状态。运行时验证 V4 静态烘焙源指纹；最终检查所有已有 Git 跟踪文件保持不变。

改善主要是叶片受光正确性与局部投影细节，并不代表整体已经达到概念图 90%。植被物种/形态、地面层次和大型资产细节仍有差距。本轮没有新增模型、贴图或付费生成。

实测结果（RTX 3060 / Vulkan Forward+ / 原生 2560×1440）：同期 V5 P95 为 30.985ms；V6 两轮各 600 帧 P95 为 31.976 / 31.549ms，GPU P95 增量为 0.653 / 0.238ms，绘制提交均为 986 次。14 张固定视角、96 帧环绕及交互检查通过，F9 还原平均误差 0.023/255。对照页为 `review.html`，完整结果为 `validation.json`。
