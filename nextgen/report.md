# 2K 清晰度与场景质感修正记录

本轮完成采样诊断、材质与布局修正及独立 Godot 验证。默认入口为 `../nextgen.tscn`。上一轮 `../quality_round.tscn` 及其资源保留；本轮没有新增 Meshy 任务，新增消耗 0，累计仍为 390/800。

## 模糊、颗粒究竟来自哪里

主要不是“参考图有颗粒，所以故意做成颗粒”。代码没有添加胶片颗粒；参考图的细碎地表也不应直接转成满屏高频噪点。

|来源|检查结论|处理|
|---|---|---|
|输出尺寸|原先固定 1421×736，大窗口显示会放大；即使不放大，也没有 2K 的有效像素|默认真正输出 2560×1440，单独保留预览档，并验证两档实际输出尺寸|
|石材源纹理|旧图是约 180–200 像素宽的裁片放大至 512，并做过增亮；有效细节没有增加|重新从官方 12K PNG 母版提取，单块约 1050–1200 像素宽，保存 PNG，无放大|
|植被采样|叶片硬透明裁切，细草轮廓接近或小于像素；MSAA 本身不能解决全部透明边缘与材质采样问题|叶片启用 alpha-to-coverage，保留 mipmap；对比 MSAA、原生 FSR2、超采样|
|地表高频细节|关闭底色后密集“脏碎”观感明显变化；关闭 SSAO 并未整体消除，法线和阴影也有贡献|压低地表颜色细对比与法线强度，保留宏观土壤、苔藓变化；提高最终档 SSAO 与阴影采样质量|
|模型与构图|均质叶团、规则石板、重复纹理和稀疏森林，即使渲染清晰仍像搭建样例|重建弯道与长短石板，替换不合适的阔叶简模，增加真实植物变体及中层灌木|

这里的“颗粒”包含真实纹理、锯齿、细叶轮廓、法线响应和阴影采样，不能用单一噪声指标概括。[隔离局部图](probe_ground_100pct.png) 与各 `probe_*_close.png` 保留供核对；`probe_roi.json` 只是局部像素变化统计，不是视觉质量分数。

## 第一轮：固定 2K 对比采样

同一批旧资产、同一构图、同一路径，预热 6 秒后记录 600 帧，RTX 3060、Forward+，性能测试关闭垂直同步。

|配置|P50 / P95 毫秒|采用情况|
|---|---|---|
|原生 2K、4× MSAA、覆盖率抗锯齿|16.304 / 21.985|保留为轻量采样选项|
|原生 2K FSR2|14.505 / 20.238|保留诊断入口，未选为默认|
|2K 输出、1.25 倍超采样、4× MSAA|20.204 / 26.444|选为最终画质档基础|

原像素局部图中超采样对细草和纹理边缘更平滑，且没有时域历史重建的依赖；其开销仍在本机预算内，因此选择该方案。不是声称 FSR2 在所有场景都较差，也没有证明任意运动都完全无闪烁。[叶片局部](aa_leaves_100pct.png)、[石材局部](aa_stone_100pct.png)、[性能原始数据](comparison.json)。

## 第二轮：资产与合成改动

- 52 块长短不同的石板按弧长排列，弯道共享径向接缝；增加倒角、小缺口与局部浅凹槽，生成正确绕序、法线和切线。多数细裂纹仍是材质表达，并非逐条裂纹建模。
- 干石材底色、法线、粗糙度分别处理；修正首次合成偏黄及侧面 UV 拉伸，统一灰米色。地面降低高频颜色对比和法线强度；水面仍采用本地非自发光材质。
- 草簇减少极细草叶并加宽主要轮廓，花朵降低高度和密度；补充 Fab 03、04 的独立蕨类变体与 Fab 05 林下植物，避免把整个多变体素材包缩成一小团。04 只选 0、3、4、5、6，03 只选 0、4、5、6，排除过低面数候选。
- 扩充外围树木、中层 Hazel/Bramble 与近地植物遮挡。主场景不采用整株 billboard；单片叶片仍可能使用透明裁切几何，这是三维植被的叶片表达。
- 试制的无纹理阔叶简模在近景显得过于人工，已从主场景移除；候选文件保留但标记未采用。九个采用的独立资产条目见 [清单](assets/catalog.json)。

原材质来自 [ambientCG Tiles130](https://ambientcg.com/view?id=Tiles130)，CC0。12K PNG 原包、本地 SHA256 和裁片范围见 `source/` 与 [纹理清单](textures/catalog.json)。SHA256 是本地归档记录，不是声称与上游公布校验值比对。Fab 文件沿用已获取时的许可，仅在本地工程复用。

## 最终验证与使用

最终为 2560×1440 输出，内部缩放设置 1.25，对应名义 3200×1800 三维采样；4× MSAA、叶片覆盖率抗锯齿、无 TAA/FXAA。最终完整场景 P50 **24.339 ms**，P95 **27.667 ms**，低于本轮 33.3 ms 目标。末帧 675 次绘制、约 934 万渲染图元，包含渲染通道开销，不能直接当作资产唯一三角形总数。

- 三视角、同构图 2K 旧资产对照、四组局部移动序列，以及完整环绕 48 个姿态均已保存。完整环绕俯角覆盖 10–60 度，同时改变缩放；48 张图是离散姿态，不是 48 FPS 录像。
- 相机平移/重置、F1/F2 实际输出尺寸、统一根节点缩放、52 块道路切线、LOD 远处 0/近处 24 个高档实例检查通过，见 [smoke.json](smoke.json)。
- 九项采用的独立资产均在真实 Forward+ GPU 下加载并包含网格，见 `assets_gpu.log`。最终 GPU 验证日志没有 ERROR。
- 几何脚本检查通过。无头导入日志仍包含本机证书存储、语言服务退出及用户目录设置写入错误，与最终 GPU 场景运行区分记录。早期被修复的贴图导入与脚本试验失败日志保留，不作为通过依据。

打开 [验收页面](review.html)，默认按 100% 像素显示，可滚动或切换适应窗口；包含原始 2K 帧播放。实际 Godot 操作：右键旋转，WASD/方向键平移，滚轮缩放，R 重置，F1 预览，F2 2K 画质。命令行可加 `--profile=preview`；诊断可加 `--aa=msaa|fsr2|ssaa`。最终测试可复跑 `run_reviews.ps1 -Round Final` 和 `-Round Assets`。

## 与次世代成品仍有差距

清晰度和运行条件已改善，但不能把这一轮称为次世代成品或 90% 还原。外围森林仍未形成参考图那样连续的树冠与丰富物种，低角度尤其显露场地平坦、外围稀疏；部分树冠与灌木仍有生成模型的均质叶团。石板还存在相同风化图案重复，刻字造型和精细破损不足。水洼仍偏简化，缺少可信的环境反射与边缘湿润过渡；小型建筑、发光遗迹也仍是较粗的旧模型。

完整环绕确认场景拥有真实空间厚度、遮挡和植被枝叶，不是单张概念图投影，但不代表任意穿入枝叶或任意近距离都不会穿帮。后续应优先重做关键植物与遗迹母版、补齐森林结构和地形微起伏，再提升间接光与湿材质；继续加锐化或单纯堆面数无法解决这些差距。
